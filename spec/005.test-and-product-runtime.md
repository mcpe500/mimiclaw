# 005. Test Infrastructure Fixes + Host Product Runtime

## Prompt
Fix all compilation blockers for unit tests and build the host runtime product experience.

## Goal
1. Make all 207 unit tests compile and pass on host (Linux/Termux)
2. Build a runnable MimiClaw binary that works like OpenClaw (setup wizard → configure channels → run autonomously)

## Why
MimiClaw pivoted from ESP32-only to dual-target. Test infrastructure needed 21 shim fixes. Host runtime needed config system, setup wizard, message bus, and HTTP client to be a real product.

## Codebase
- `test/shims/` — ESP-IDF API stubs for host compilation
- `core/host/` — Host-specific runtime (config, setup wizard, message bus)
- `core/shims/` — Platform shims for host binary
- `main/` — Shared business logic (channels, tools, auth, agent)

## Pseudocode

### User Flow
```
$ cd core && make setup && make run
First run? → setup wizard → save config.json → start channels → agent loop
Second run? → load config.json → start channels → agent loop
```

### Config System
```
config_init(path) → set file path
config_exists() → access(path, F_OK)
config_load() → fopen → cJSON_Parse → map to struct → fclose
config_save() → cJSON_Create → cJSON_Print → fopen → fwrite → fclose
```

### Setup Wizard
```
print banner → read provider → read api_key → read model
→ for each channel: enable? → read token
→ config_save() → print summary
```

### Message Bus (host)
```
init: pthread_mutex_init + pthread_cond_init + circular buffer alloc
push: lock → write tail → signal condvar → unlock
pop: lock → timedwait condvar → read head → unlock
```
